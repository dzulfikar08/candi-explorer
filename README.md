# Candi Explorer

[![CI](https://github.com/dzulfikar08/candi-explorer/actions/workflows/ci.yml/badge.svg)](https://github.com/dzulfikar08/candi-explorer/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Interactive 3D explorer for Indonesian temples (candi), built with Three.js, React, shadcn/ui and
Tailwind on Vite: 32 sites from Central, East and West Java, Sumatra and Bali, from Borobudur and
Prambanan to the brick gates of Majapahit's Trowulan and the cliff shrines of Gunung Kawi. Pick a
temple on the map or from the menu under the title; each has its own address (`/prambanan`,
`/sewu`, …).

**Live: https://candi-explorer.by.dzulfikar.com**

Requires a browser with WebGL 2. Walk mode needs a mouse and keyboard; orbit and the tour work on
touch devices.

## Development

Needs [Bun](https://bun.sh) 1.x.

```bash
bun install
bun run dev        # http://localhost:5173
bun run build      # static site in dist/
bun run typecheck
bun run test
```

## What you can do

- **Map of Indonesia** (the home page): every temple on the map, plus 141 more known temples marked
  "coming soon" (from Indonesian Wikipedia's _Daftar candi di Indonesia_ and Wikidata, positioned
  from their articles or OpenStreetMap; the list is in `src/candi/planned.ts`). Nearby temples merge into one
  numbered marker that zooms in when clicked; drag, scroll or pinch to move around. The side list
  groups temples by region and filters as you type a name, regency or island. Pick a temple to see
  where it is, then "Explore in 3D". "All temples" in a temple brings you back to it on the map.
- **Switch temples** without the map: previous / next, or the search field in the title card.
- **Sources**: every temple's notes end with the references its facts come from, opening in a new
  tab, and a "Places to look at" list that matches the numbered markers.
- **Orbit**: drag to rotate, scroll to zoom. The view slowly circles the temple until you take
  control. Numbered markers fly the camera to a feature and open its notes.
- **Walk**: first-person, `W A S D` / arrows, `Shift` to hurry, click to capture the mouse, `Esc` to
  release. Stairs are climbable and walls block you. Needs a mouse and keyboard.
- **Pradaksina tour**: walks the pilgrim route, circling each shrine clockwise with the temple on the
  right. Notes follow the section; pause, skip, 1–8× speed.
- **Three realms**: tints the three cosmological zones, foot / body / roof (Kamadhatu / Rupadhatu /
  Arupadhatu on Buddhist temples, Bhurloka / Bhuvarloka / Svarloka on Hindu ones).
- **Time of day** (WIB): real solar position for the temple's latitude/longitude and today's date,
  with morning mist.

## How the models are made

Everything is procedural; there are no model or texture assets. Each temple's code loads only when
it is opened.

- `src/candi/kit/`: the shared kit. `shrine.ts` turns a `ShrineSpec` (plinths, foot, body with a
  chamber and doorways, niches, stairs, stepped roof tiers with ratna or stupa finials) into
  geometry; `compound.ts` places shrines, walls, courts and terraces from data and generates the
  tour; `enclosure.ts` has courtyard walls with paduraksa and candi bentar gates, terraces and
  sunken courts; `ruin.ts` collapses a shrine into rubble on its standing foot; `site.ts` merges
  everything into one mesh per realm and material and instances repeated shrines.
- `src/candi/<temple>/`: each temple's dimensions, layout, notes, hotspots and horizon, with its
  sources in the file header. `*.test.ts` files check published counts and heights (Borobudur's
  432 niched Buddhas and 72 perforated stupas, Prambanan's 224 perwara, Sewu's 249 temples).
- `src/candi/borobudur/` is fully custom: redented terraces, galleries, mudras by direction,
  perforated stupas with lattice alpha maps.
- `src/render/stone.ts` paints andesite masonry, paving, red brick, relief panels and stupa lattices
  on canvases at startup.
- `src/render/environment.ts`: sky, sun, mist, terrain (with a cut-out for sunken sites such as
  Sambisari), trees, the approach road, and horizon volcanoes placed at their true bearings with
  their true angular height.
- `src/map/`: the map page's non-React engine (`view.ts`: markers, clustering, pan and zoom).
  `land.ts` is coastline path data generated by `scripts/build-map.ts` from
  [Natural Earth](https://www.naturalearthdata.com) 1:50m countries (public domain); rerun
  `bun scripts/build-map.ts` to regenerate it.
- `src/scene/engine.ts` runs the 3D view (camera modes, tour, hotspot projection) behind a small
  API; `src/app/` is the React UI (map page, temple page, sponsor page) built from the shadcn/ui
  components in `src/components/ui/` (Base UI flavour, `components.json`), themed in
  `src/globals.css`.
- `src/candi/photos.ts`: photos from Wikimedia Commons, shown in the notes and on the map card with
  author, licence and a link to the file page. Images load from Wikimedia's servers; none are copied
  into the repo, and their licences (CC BY, CC BY-SA, CC0, public domain) are theirs, not this
  repo's MIT licence.

Known simplifications: carving is stylised and shared between temples; many shrines reuse the
kit's generic Javanese profile; Borobudur's upper corridors are 3 m apart instead of the real ~2 m
so they can be walked; stairs are steep approximations. Each temple's notes and source header say
where its model departs from the real building.

## Adding another candi

Create `src/candi/<id>/index.ts` exporting a `CandiDefinition` (`src/candi/types.ts`): topics,
hotspots, horizon landmarks, sources, a home camera view, realm labels, a site setting, and a
`build(textures)` — usually `buildCompound(...)` from the kit. Register it in `src/candi/index.ts`
with its location, coordinates and region (the map reads them without loading the temple; a test
checks they match). `src/candi/mendut/index.ts` is the smallest complete example. See
[CONTRIBUTING.md](CONTRIBUTING.md) for the full checklist.

## Deploying

`bun run deploy` builds and publishes `dist/` as a Cloudflare Worker with static assets
(`wrangler.jsonc`). The config is pinned to the maintainer's account and custom domain; in a fork,
change `account_id` and `routes` (or drop `routes` and set `"workers_dev": true`). `dist/` is a
plain static site, so any static host works too.

## Promo card and sponsor page

Under the title and in the map sidebar, a card rotates (every 5 s) through other products by the
same makers: the list is in `src/data/sponsor.ts`, the card in `src/app/promo.tsx`, icons in
`public/ad-icons/`. Links carry `utm_source=candi-explorer`. It pauses on hover or focus, stays
still with reduced motion, hides in walk mode, and on phones shrinks to a name pill. "Your product
here" opens `/advertise`, the sponsor page (Rp 19.900 a month, paid by QRIS through Pakasir). Its
checkout button stays disabled until `PAKASIR_SLUG` in `src/data/sponsor.ts` is set. Forks should
replace or remove both.

## Analytics

`index.html` loads [Revklik](https://revklik.com) (cookieless; bots and datacenter traffic are
excluded) for the "Candi Explorer" site. Forks should remove the script tag or use their own site id.
The "N online · M visitors" line under the title reads Revklik's public live-widget feed
(`src/visitors.ts`); it stays hidden if the feed is unreachable.

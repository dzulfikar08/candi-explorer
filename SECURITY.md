# Security Policy

Candi Explorer is a static client-side site with no backend, accounts, or stored user data. Security
issues are still possible (e.g. in dependencies or the deployment configuration).

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/dzulfikar08/candi-explorer/security/advisories/new)
or email **dzulfikar.at@gmail.com**.

You can expect an acknowledgement within 7 days. Only the latest version on `main` (deployed at
https://candi-explorer.by.dzulfikar.com) is supported.
